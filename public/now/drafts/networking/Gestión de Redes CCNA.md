- **SOHO (Small Office/Home Office Network)**. Categoría de negocio que opera desde una pequeña oficina ubicada en el hogar o casa.
# Tipos de red

- **Internet**. Colección mundial de redes interconectadas (**internetwork**) que intercambia información sobre estándares comunes.
	- La transmisión se realiza por medio de cables telefónicos, cables de fibra óptica, transmisiones inalámbricas, etc.

## Redes Locales

- Existen redes de diversos tamaños, desde simples (2 dispositivos) hasta complejas con miles de dispositivos.
- Oficinas pequeñas, hogares y oficinas domésticas son SOHO (**Small Office/Home Office**).
	- Permiten compartir recursos, como impresoras, documentos, imágenes, etc. entre usuarios locales.
- **Redes domésticas pequeñas**. Conexión de algunas computadores entre sí.
- **Redes domésticas**. SOHO permite que computadoras de oficina/hogar se conecten a una red corporativa o accedan a recursos compartidos centralizados.
- **Redes medianas a grandes**. Pueden tener ubicaciones con cientos o miles de host interconectados.
- **Redes mundiales**. Red de redes que conectan millones de host en el mundo.

## Dispositivos Domésticos

Diversos objetos del hogar pueden conectarse al Internet para ser configurados o controlados remotamente.
- **Sistema de Seguridad**. Sistemas de seguridad, iluminación, etc. pueden ser supervisados y configurados de forma remota.
- **Dispositivos**. Electrodomésticos como refrigeradores, cocinas, etc. pueden conectarse al Internet para ser administrados y supervisados de manera remota.
- **Televisor Inteligente**.
- **Consola de Juegos**.
