Organización de Archivos Digitales

1. **Establecer objetivos para la organización de archivos digitales**.

Definir qué se quiere lograr.
*¿Quién necesita entender el sistema de organización de archivos digitales?*
*¿Cuando se iniciara el proyecto?, ¿Cuanto tiempo se invertirá?*
*¿Como se estimara la tasa de éxito?*

2. **Obtener información sobre el método actual de organización de archivos**.

Conocer y comprender prioridades y dificultades.
*¿Qué le gusta y qué no le gusta del actual sistema de organización de archivos informático?*
*¿Qué es confuso o difícil de encontrar?*
*¿Cómo mejorarías la organización de los archivos?¿Qué te ha funcionado bien antes?*

**Recursos**.
**Herramientas empresariales**. Computador y software para compartir archivos en línea.
**Materiales para tomar notas**. Configurar recordatorios en el calendario y considerar usar herramientas de colaboración visual o cuadernos digitales para organizarte.
**Tiempo**. Dividir tareas en partes manejables o en sesión.

3. **Eliminar y archivar archivos y carpetas antiguos del computador**

Si existen archivos o documentos duplicados que no se volverán a consultar, es necesario eliminarlos.
Si no se decide sobre si conservar o no un archivo es necesario guardarlo en "*Archivados*"

4. **Crear una estructura de carpetas**

Organización basada en "**Nombres**".
Organización basada en "**Fechas**".
Organización basada en "**Proyectos**".
Organización basada en "**Departamento**"

5. **Definir una convención de nombres de archivos**

Comenzar con la categoría más amplia al principio del nombre, como año, departamento, etc.

Definir protocolos de nomenclatura de metadatos y etiquetas.

6. **Establecer un sistema de control de versiones**

Utilizar un solo archivo, guardado en un servidor compartido, para que puedan trabajar de manera colaborativa en tiempo real

Usar un procesador de texto con control de cambios para registrar las modificaciones realizadas

Opcional. Establecer un orden y terminación de los nombres de archivos, puede indicar cada etapa de un proceso (draft, edits, revision, ...)

7. **Organizar los archivos de imagen efectivamente**

Utilizar el mismo sistema de organización de archivos para las fotos. No obstante es posible establecer un sistema basado en eventos.

Establecer una convención de nombres para las imágenes que sea especifico y descriptivo para facilitar la búsqueda-

8. **Gestionar archivos exclusivos de liderazgo o confidenciales**

Incorporar protección de datos a la estrategia de organización de archivos digitales.
- Establecer niveles de acceso para los archivos y carpetas con el fin de limitar el acceso a personas externas
	- Establecer contraseñas para archivos y carpetas
	- Otorgar acceso de sólo lectura
	- Evitar que las personas descarguen archivos
	- Establecer permisos por usuario, archivo o grupo
	- Cifrar archivos confidenciales
	- Aprovechar funciones de cumplimiento

Establecer un sistema para determinar que configuración de uso compartido puede usar cada archivo.

9. **Organizar grandes cantidades de archivos por años o trimestres**

Si es necesario modificar el nombre de varios archivos, es necesario usar aplicaciones de modificación en masa, que permitan además agregar detalles a los nombres de los archivos.

10. **Comunicar sobre el nuevo sistema de organización**

Realizar una reunion sobre las nuevas pautas de organización de archivos y carpetas
- Comunicar las instrucciones mediante correo electrónico.
- Publicar las pautas de la aplicación en el chat grupal
- Crear una carpeta de plantillas y subcarpetas.
Informar sobre el proceso de respaldo de información, tanto de manera local como en servicios de nube.

11. **Mantener el sistema de organización de archivos**

Implementar tareas de automatización en el sistema de organización de carpetas
Establecer un periodo de mantenimiento periódico para mover los archivos extraviados
