Símbolos o palabras reservadas empleadas para ejecutar operaciones de **recuperación & modificación** en la información. Empleados para construir filtros, comparadores, manipulación de datos.

- Operadores **Aritméticos**. Permite realizar cálculos matemáticos sobre valores numericos `+, -, *, /, %`
  
- Operadores **Comparación**. Permite realizar comparación de dos expresiones y evaluar condiciones `=, !=, <, >, <>, <=, >=`
  
- Operadores **Lógicos**.  Permite combinar expresiones condicionales `AND, OR, NOT`
  
- Operadores de **Filtrado y Pertenencia**. 
  `IN, NOT IN, BETWEEN, NOT BETWEEN, LIKE, NOT LIKE, IS NULL, IS NOT NULL`
	- LIKE. `%` (Cero o mas caracteres), `_` (Exactamente un caracter)
	  
- Operadores **Conjunto**. Permite combinar los resultados de varias queries `UNION, UNION ALL, INTERSECT, INTERSECT ALL, EXCEPT, EXCEPT ALL, MINUS`
  
- Operadores de **Subconsultas**. Utilizadas en subconsultas `EXISTS, NOT EXISTS, IN, NOT INT, ANY, SOME, ALL`
  
- Operadores **NULL**. Utilizado en comparaciones NULL `IS NULL, IS NOT NULL, IS DISTINCT FROM, IS NOT DISTINCT FROM, <=>, IS TRUE, IS FALSE, IS UNKNOWN`
