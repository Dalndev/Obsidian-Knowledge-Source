Subsets de SQL para definir y gestionar las estructuras "database objects". Permite a los administradores y desarrolladores definir el schema de una base, relacionales entre tablas, etc.

**CREATE**. Sentencia utilizada para definir y crear una una tabla en una base de datos. Es necesario especificar propiedades como `Table Name, Column Names, Data Types, Constraints, Primary Keys, Foreign Keys`

  > Establece la estructura de la tabla y define como la información va ha ser almacenada y organizada.

[IBM | CREATE TABLE](https://www.ibm.com/docs/es/db2-for-zos/12.0.0?topic=statements-create-table) | [PostgreSQL | CREATE TABLE](https://www.postgresql.org/docs/18/sql-createtable.html)

```SQL
CREATE TABLE [IF NOT EXISTS] table_name
    ([ { column_name data_type [column_constraint [...] | table_constraint]} [, ...]])
    
-- column_constraint

[CONSTRAINT constraint_name]
{ NOT NULL | 
  NULL |
  CHECK (expression) |
  DEFAULT default_expr |
  GENERATED ALWAYS AS (generation_expr) [STORED | VIRTUAL] |
  GENERATED {ALWAYS | BY DEFAULT} AS IDENTITY [(sequence_options)] |
  UNIQUE [NULLS [NOT] DISTINCT] index_parameters |
  PRIMARY KEY index_parameters |
  REFERENCES ref_table [(ref_column)]
      [ON DELETE referential_action] [ ON UPDATE referential_actions]}
      
-- table_constraint

[CONSTRAINT constraint_name]
{ CHECK (expression) | 
  NOT NULL column_name |
  UNIQUE [NULLS [NOT] DISTINCT] (column_name [, ...] [, column_name]) index_parameters |
  PRIMARY KEY (column_name [, ...] [, column_name]) REFERENCES ref_table [(ref_column [, ...] )] 
    [ON DELETE referential_action] [ON UPDATE referential_action]}
    
-- index_parameters

[INCLUDE (column_name [, ...])]
[USING INDEX TABLESPACE tablespace_name]

-- referential_action

{ NO ACTION | RESTRICT | CASCADE | SET NULL [(column_name [, ...])] | SET DEFAULT [(column_name [, ...])]}
```

Eg.
```SQL
CREATE TABLE films (
    code        char(5) CONSTRAINT firstkey PRIMARY KEY,
    title       varchar(40) NOT NULL,
    did         integer NOT NULL,
    date_prod   date,
    kind        varchar(10),
    len         interval hour to minute
);

CREATE TABLE distributors (
     did    integer PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
     name   varchar(40) NOT NULL CHECK (name <> '')
);
```

**ALTER**. Utilizada para modificar la estructura de una tabla existente. Ya sea agregando, eliminando o modificando columnas

[IBM | ALTER TABLE](https://www.ibm.com/docs/es/db2-for-zos/12.0.0?topic=statements-alter-table) | [PostgreSQL | ALTER TABLE](https://www.postgresql.org/docs/18/sql-altertable.html)

```SQL
ALTER TABLE [IF EXISTS] [ONLY] name [*]
    action [, ...]

ALTER TABLE [IF EXISTS] [ONLY] name [*]
    RENAME [COLUMN] column_name TO new_column_name
    
ALTER TABLE [IF EXISTS] [ONLY] name [*]
    RENAME CONSTRAINT constraint_name TO new_constraint_name

ALTER TABLE [IF EXISTS] name
    RENAME TO new_name
    
-- action

  ADD [COLUMN] [IF NOT EXISTS] column_name data_type [COLLATE collation] [column_constraint [...]]
  DROP [COLUMN] [IF EXISTS] column_name [RESTRICTI | CASCADE]
  ALTER [COLUMN] column_name [SET DATA] TYPE data_type [COLLATE collation] [USING expression]
  ALTER [COLUMN] column_name SET DEFAULT expression
  ALTER [COLUMN] column_name DROP DEFAULT
  ALTER [COLUMN] column_name {SET | DROP} NOT NULL
  ALTER [COLUMN] column_name SET EXPRESSION AS (expression)
  ALTER [COLUMN] column_name DROP EXPRESSION [IF EXISTS]
  ALTER [COLUMN] column_name ADD GENERATED {ALWAYS | BY DEFAULT} A IDENTITY [(sequence_options)]
  ALTER [COLUMN] column_name {SET GENERATED {ALWAYS | BY DEFAULT} | SET sequence_option | RESTART [[WITH] restart]} [...]
  ADD table_constraint [ NOT VALID ]
  ADD table_constraint_using_index
  ALTER CONSTRAINT constraint_name 
  VALIDATE CONSTRAINT constraint_name
  DROP CONSTRAINT [ IF EXISTS ]  constraint_name [RESTRICT | CASCADE]
  
-- column_constraint

[CONSTRAINT constraint_name]
{ NOT NULL | 
  NULL |
  CHECK (expression) |
  DEFAULT default_expr |
  GENERATED ALWAYS AS (generation_expr) [STORED | VIRTUAL] |
  GENERATED {ALWAYS | BY DEFAULT} AS IDENTITY [(sequence_options)] |
  UNIQUE [NULLS [NOT] DISTINCT] index_parameters |
  PRIMARY KEY index_parameters |
  REFERENCES ref_table [(ref_column)]
      [ON DELETE referential_action] [ ON UPDATE referential_actions]}
      
-- table_constraint

[CONSTRAINT constraint_name]
{ CHECK (expression) | 
  NOT NULL column_name |
  UNIQUE [NULLS [NOT] DISTINCT] (column_name [, ...] [, column_name]) index_parameters |
  PRIMARY KEY (column_name [, ...] [, column_name]) REFERENCES ref_table [(ref_column [, ...] )] 
    [ON DELETE referential_action] [ON UPDATE referential_action]}
  FOREIGN KEY (column_name [, ...]) REFERENCES ref_table [(ref_column [, ...] )]
    [ON DELETE referential_action] [ON UPDATE referential_action]
    
-- table_constraint_using_index

[CONSTRAINT constraint_name]
{UNIQUE | PRIMARY KEY} USING INDEX index_name

-- index_parameters

[INCLUDE (column_name [, ...])]
[USING INDEX TABLESPACE tablespace_name]

-- referential_action

{ NO ACTION | RESTRICT | CASCADE | SET NULL [(column_name [, ...])] | SET DEFAULT [(column_name [, ...])]}
```

**DROP**. Remueve una tabla y la información de manera permanente de una base datos. La operación elimina completamente la estructura e información a menos de que exista un respaldo.

```SQL
DROP TABLE [IF EXISTS] name [, ...] [CASCADE | RESTRICT]
```

**TRUNCATE**. Remueve todas las filas de una tabla, reseteando la tabla a su estado inicial (Estado Vacío), pero mantiene la estructura (columnas, restricciones, etc.)

```SQL
TRUNCATE [TABLE] [ONLY] name [*] [, ...]
    [RESTART IDENTITY | CONTINUE IDENTITY] [CASCADE | RESTRICT]
```
