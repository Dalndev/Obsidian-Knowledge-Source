**Revisión Técnica (SQL)**.

**SQL (Operadores)**.
Símbolos o palabras reservadas empleadas para ejecutar operaciones de **recuperación & modificación** en la información. Empleados para construir filtros, comparadores, manipulación de datos.

- Operadores **Aritméticos**. `+`, `-`, `*`. `/` (Cálculos Matemáticos)
- Operadores **Comparación**. `=`, `!=`, `<`, `>` (Comparación de Valores)
- Operadores **Lógicos**. `AND`, `OR`, `NOT` (Combina Multiples Condiciones)
- Operadores **Conjunto**. `UNION`, `INTERSECT`, `EXCEPT` (Combina multiples Queries)

**SQL (Sentencias)**.
- **SELECT**. Recuperar información de una o más tablas de una base de datos, en donde se puede aplicar filtros, ordenamientos y varias operaciones (*Joins, Subqueries, Aggregations*) sobre la información. 
- **INSERT**. Agrega nuevas filas de información en una tabla donde se especifica el valor a insertar en cada columna. 
- **UPDATE**. Permite modificar información registrada en una tabla ya sea una columna o filas especificando una condición.
- **DELETE**. Remueve filas de una tabla aplicando clausulas para filtrar y afectar a filas especificas basado en condiciones.
