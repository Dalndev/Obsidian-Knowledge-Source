>*Microsoft Entra ID determina quién puede autenticarse, a qué puede acceder y bajo qué condiciones.*

**Microsoft Entra ID** es un servicio de identidad que permite la administración de la **identidad**, **autorización** y **autenticación** para el acceso recursos (usuarios, documentos, imágenes, etc.) de la organización mediante el cumplimiento de directivas.

La comprobación realiza tanto como validación de identidades de usuario, validación de condiciones de acceso (**Conditional Access**), comprobación de permisos hasta cifrado de canales de conexión y otros procesos para verificar el acceso a recursos. 

Estas diferentes responsabilidades permite a Microsoft Entra cubrir la identidad, el acceso, la gobernanza y seguridad en un punto centralizado o un administrador especializado.

**Centro de Administración de Microsoft Entra**.

Portal basado en web que proporciona una experiencia administrativa unificada para la gestión de usuarios, grupos, métodos de autenticación, directivas de acceso condicional, supervisión de seguridad de identidad y controlar el acceso en toda la organización.

**Dashboard/Home**. 
Sección que incluye información sobre el tenant, actividades recientes, accesos directos, guías de implementación, etc.
