## FaaS (Functions as a Service)
---
FaaS (Functions as a Service) es un *paradigma* para la creación de aplicación, los cuales se basan en la programación de partes de aplicaciones con **reglas de eventos** que activan el código. Esta activación o ejecución es facturada por el proveedor de la nube la cual mide la memoria, uso de CPU y ámbito de las funciones.

Aunque permite crear aplicaciones sin preocupación del entorno de ejecución, se debe considerar que no todas las cargas de trabajo se prestan a un modelo de activación de operación única. Ademas no todo el código es separable ya que este puede tener dependencias las cuales necesiten instalaciones, generando un complejidad.
