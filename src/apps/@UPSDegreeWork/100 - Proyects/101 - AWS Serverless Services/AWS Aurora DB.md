Sistema de administración de bases de datos relacionadas, creado para la nubo, con compatibilidad MySQL y PostgreSQL. Ofrece rendimiento y disponibilidad de bases de datos comerciales 

“Configurar características clave”: “Seguridad, copias de seguridad automatizadas, elección de instancias y almacenamiento para necesidades de precio-rendimiento y precio-predictibilidad, sin servidor, hasta 15 réplicas de lectura de baja latencia, auditoría y más"

Integración con otros servicios  para realizar análisis y estraer información o supervisar tendencias: Amazon S3, AWS Backup, Amazon DevOps Guru, AWS CloudTrail, Amazon Redshift, Amazon GuardDuty, Amazon CloudWatch, Amazon SageMaker, Amazon Comprehend, AWS Lambda, Amazon EKS y AWS Secrets Manager.
