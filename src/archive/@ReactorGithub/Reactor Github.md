## Github Copilot
--- 
- Herramienta para brindar sugerencia de código mediante API **Codex** de **OpenAI**.
	- Aproximadamente el 40% del código es generado por IA
	- *Github Developer Student Pack*
	- **Agentes**: *Bots de copilot* que permiten obtener un contexto para realizar la generación de texto, en base a las referencias del ambiente que analiza.
		- @workspace
		- @terminal
		- @vscode
	- **Comando**: *Explain*, asigna un agente de tipo terminal para explicar la selección del terminal integrado.
		- `/doc`: Genera documentación para el código
		- `/test`: Genera una prueba unitaria para el código
		- `/fix`: Realiza una corrección en el código seleccionado.
		- `/explain`: Genera una explicación del código seleccionado.
		- `/help`: Explica una sobre las funcionalidades del asistente.
- *Github Actions*: Funcionalidades de Devops para los repositorio de código.

*Aplicado en documentación, generación de código, devops, ...*
