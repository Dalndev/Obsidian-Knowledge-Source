# Bus de eventos

Es un bus de eventos sin servidor que facilita la creación de aplicaciones basadas en eventos a escala utilizando eventos generados a partir de sus aplicaciones, aplicaciones de software como servicio SaaS de terceros y servicios de AWS. Actúa como un enrutador de eventos para enrutar sus eventos, desacoplando completamente los orígenes y destinos de sus eventos. Puede crear reglas en el bus de eventos para permitir que cada suscriptor elija qué eventos quiere consumir
