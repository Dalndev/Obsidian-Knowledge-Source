Es un servicio proveído por Amazon en donde se almacena bits de código, los cuales pueden ser ejecutados bajo demanda.
Es un servicio informático sin servidor y basado en eventos que le permite ejecutar código para prácticamente cualquier tipo de aplicación o servicio backend sin necesidad de aprovisionar o administrar servidores.
**Ejecuta el código en respuesta a eventos y administra automáticamente los recursos de computación, lo que acelera el paso de una idea a una aplicación de producción moderna.**

Use [[AWS Simple Storage Service]] para activar el procesamiento de datos de AWS Lambda en tiempo real
