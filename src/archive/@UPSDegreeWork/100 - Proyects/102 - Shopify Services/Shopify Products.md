Permite crear y actualizar productos en la tienda, en donde es posible tener variantes del mismo producto, las cuales no son mas que diferentes versiones del mismo producto (Diferentes color, talla).
- Pertenecen a un [[Shopify Collect]]

## Recurso Product
---
| Atributo     | Tipo de Dato | Sub-Atributos |
| ------------ | ------------ | ------------- |
| body_html    |  String            |  -             |
| id           |  Number            | -              |
| options      |  String            | -              |
| product_type | String             | -              |
| status       | String             |  [active, archived, draft]             |
| title        |  String            | -              |
| variants     |  Array            | -              |
| vendor             |  String            |  -             |
