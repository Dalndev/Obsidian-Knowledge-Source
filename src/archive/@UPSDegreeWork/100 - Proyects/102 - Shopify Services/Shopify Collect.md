Es un recurso que conecta un [[Shopify Products]] a una colección personalizada
- Gestión la relación entre productos y colección personalizada, en donde para cada producto de una colección, la colección rastrea el ID tanto del producto como de la colección.
- Un producto puede estar en mas de una colección el cual sera conectado
- Colección son para colocar productos.

## Recurso Collect
---
| Atributo      | Tipo de Dato | Sub-Atributos |
| ------------- | ------------ | ------------- |
| collection_id |  number            |               |
| id            |  number            |               |
| position      |  number            |               |
| product_id              | number             |               |
