JSM es una plataforma que ofrece funcionalidades para la gestiona de servicios a equipos de TI.
#### Términos clave
---

| Termino                                                              | Concepto                                                                                                                                                                                                                                           |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agente*                                                              | Usuarios con el rol ***Service Desk Team*** que trabajan en las solicitudes de los clientes.                                                                                                                                                       |
| Activo                                                               | Son los activos de hardware, software o de información que una organización.                                                                                                                                                                       |
| Cambio*                                                              | Es la acción de añadir, modificar o eliminar algo que podría afectar los servicios de TI.                                                                                                                                                          |
| Base de datos de gestión de configuración (CMDB)*                    | Las **CMDB** almacenan información sobre la configuración de los elementos dentro de una organización, incluido el *hardware, software, sistemas, instalaciones y personal*.                                                                       |
| Cliente*                                                             | Usuarios que solicitan ayuda dentro del servicio, estos pueden ser internos (empleados) o externos.                                                                                                                                                |
| Gestion de servicios empresariales (ESM)*                            | ESM es la extensión de los principios de ITSM para permitir una mejor presentación de servicios para equipos comerciales como RR.HH, legal, marketing y finanzas.                                                                                  |
| Incidente*                                                           | Evento imprevisto que puede interrumpir o reducir la calidad de un servicio y requiere una respuesta de emergencia.                                                                                                                                |
| Biblioteca de Infraestructura de Tecnología de la Información (ITIL) | ITIL es un conjunto de mejores prácticas diseñadas para ayudar a una organización a obtener un valor óptimo de TI al alinear servicios con la estrategia comercial.                                                                                |
| Incidencias*                                                         | Forma de representar las actividades en JSM para administradores y agentes, lo cual incluye un incidente, cambio, problema o solicitud de servicio.                                                                                                |
| Tipos de problemas                                                   | Brindan a las solicitudes características como campos, estados de flujo de trabajo.                                                                                                                                                                |
| Gestión de servicios de TI (ITSM)*                                   | Forma en que los equipos de TI gestionan la prestación integral de servicios de TI a los clientes. Incluye todos los procesos y actividades para diseñar, crear, entregar y dar soporte a los servicios de TI. "*TI se presenta como un servicio*" |
| Lenguaje de consulta de JIRA (JQL)                                   | ...                                                                                                                                                                                                                                                |
| Base de conocimientos                                                | Biblioteca en línea de autoservicio con información sobre un producto, servicio, departamento o tema.                                                                                                                                              |
| Esquema de objeto                                                    | Recopilación de información en Activos que se utiliza para el seguimiento de activos, elementos de configuración, recursos, etc. "*Ayudan a los usuarios a comprender y visualizar las relaciones críticas entre todos los objetos de Activos*".   |
| Problema*                                                            | Causa subyacente de incidentes recurrentes o prevenibles.                                                                                                                                                                                          |
| Proyectos*                                                           | Conjunto de problemas que comparten un propósito o contexto. Los problemas agrupados pueden configurarse desde restricciones de visibilidad hasta flujos de trabajo disponibles.                                                                   |
| Solicitudes*                                                         | Representación de los problemas para ayudar a quienes los buscan. Son tickets enviados por clientes o usuarios finales.                                                                                                                            |
| Tipos de solicitud                                                   | Define y organiza solicitudes entrantes para atender a los clientes de manera eficiente.                                                                                                                                                           |
| Solicitud de servicio*                                               | Solicitud formal del usuario para que se le proporcione algo.                                                                                                                                                                                      |
| Flujos de trabajo                                                    | Representan la ruta secuencial que sigue una incidencia desde su creación hasta su                                                                                                                                                                 |
| Lenguaje de Consulta de Activos (AQL)                                | Formato de lenguaje de JSM para realizar consultas de búsqueda de activos y elementos de configuración (EC).                                                                                                                                       |
