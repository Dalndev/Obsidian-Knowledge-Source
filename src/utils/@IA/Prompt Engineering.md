Desarrollo de prompts (*indicaciones/textos*) precisos, con el fin de obtener resultados de IA basado en un contexto.
- Formulación de preguntas y afirmaciones claras basados en un **contexto**.

**Prompting**: Utiliza un lenguaje natural, para explicar a herramientas de IA a fin de obtener una respuestas.
- Especificar el tipo de contenido requerido, así como los objetivos claramente a la IA.
- Para tener eficacia, se debe incluir *contexto*; permite que se comprenda mejor el escenario y las *instrucciones*; permite especificar la acción a realizar.

**Contexto**: Otorga un trasfondo claro para generar contenido correcto y preciso

```
Recomendaciones para mejorar la experiencia de usuario en un sitio web de comercio electronico.
```

**Instrucciones Claras**: Permite tener una mayor precisión en los resultados de la IA, por lo que se debe ser explicito y directo evitando ambigüedad.

```
Explica las funciones y responsabilidades de un desarrollador de sitios web
```

**Formato**: Permite perfeccionar los resultados hasta conseguir la forma deseada, mediante la estructura o estilo de respuesta.

```
Enumera las cinco mejores herramientas para desarrolladores de sitios web
```

**Tono y Longitud**: Permite establecer una emoción en la IA, así como la profundidad de la respuesta.

```
Haz una critica profesional del siguiente diseño de pagina web
```

```
Escribe una breve introduccion(30-40 palabras) sobre la evolucion del diseño de sitios web responsivos.
```

### Tecnicas de "Prompt"
---
**Zero-Shot Prompting**
Consiste en generar una respuesta sin dar ejemplos o contexto.

```
Puedes describir rapidamente que es un hoverboard?
```

**One-Shot Prompting**
Busca extraer una respuesta a partir de un ejemplo o contexto dato

```
Traduce las siguientes oraciones del ingles al español. Aqui hay un ejemplo: 'I like playing football' --> 'Me gusta jugar al futbol'

Ahora traduce: 'She likes reading books'
```
